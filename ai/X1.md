## Gmail and Google Watchers

Host `x1` uses Google Workspace/Gmail watchers rather than local Maildir. Gmail polling runs per coding agent to preserve security isolation and prevent mailbox confusion:

- **Listener Service**: `openclaw-gmail-listener.service` is enabled for each coding agent user (`asdrubal` and `barekbaal`).
- **Pub/Sub Subscriptions**:
  - `asdrubal` subscription: `gmail-inbox-watch-asdrubal-sub`
  - `barekbaal` subscription: `gmail-inbox-watch-barekbaal-sub`
- **Shared Topic**: Both subscriptions attach to the shared GCP Pub/Sub topic `projects/<gcp-project>/topics/gmail-inbox-watch`.
- **Ingestion & Wake**:
  - The push listener script (`gmail-push-worker.js`) fetches messages when notified, writes events to `~/.openclaw/mail/events.jsonl`, marks the email as read immediately, and wakes the agent via:
    ```bash
    sudo -n /usr/local/sbin/openclaw-control wake-agent <self>
    ```
- **Sudoers**: `/etc/sudoers.d/openclaw-mail-self-wake` gives `asdrubal` and `barekbaal` permissions to run only their own `wake-agent` commands without a password.

  - `karen`: `@karenSideye_bot`

## Jira and Webhooks

Jira routing uses a central monitor-owned webhook dispatcher:

- **Receivers**: `/home/karen/webhooks/jira-receiver.js` (port `3014`) and `/home/karen/webhooks/bitbucket-receiver.js` (port `3015`), running under the user `karen`.
- **Routing Rules**: Defined in `/home/karen/webhooks/users.json`. Webhooks map incoming events (`jiraAccountId` lookup) and parse comment bodies for @-mentions.
- **Wake Action**: Incoming events queue a task inside `/home/<user>/tasks/current.md` and trigger a wake via:
  ```bash
  sudo /usr/local/sbin/openclaw-control wake-agent <agent-user>
  ```
- **Sudoers**: `/etc/sudoers.d/karen-openclaw-control` allows `karen` to execute `openclaw-control` commands (`restart-services`, `wake-agent`, `restart-and-wake`) for target coding agents.
- **Pending Mention Queue**: `/var/lib/ai-monitor/pending-mentions/` tracks unresolved mentions that are periodically audited by `ai-monitor`.

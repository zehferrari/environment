## Failure

At the initial count PH-192 had accumulated **101 agent runs**. Compact task
turns advertised native PM tools, but OpenClaw did not expose those tools to
Asdrubal. The agent repeatedly reported that it could not checkpoint, complete
the checklist, submit review, or formally record its external blocker.

The plugin registered tool factories but omitted `contracts.tools` from
`openclaw.plugin.json`. The installed OpenClaw tool loader first selects
plugins using those manifest declarations. With no declared tools, the PM
factory was not selected. The capabilities endpoint nevertheless returned all
15 tool names and runtime version 1, so PM incorrectly admitted compact turns.
Unit tests exercised the factory directly and had not caught discovery failure.

The auto-continuation policy then saw an In Progress task with active repository
execution and no formal external blocker. It sent more recovery notifications.
The chain is bounded to eight continuations per rolling twenty-minute window;
monitor recovery can start further windows. A free-text blocker report does
not establish the structured state that suppresses these notifications.

This was a workflow/tooling failure, separate from the remaining AWS issue.
The existing `lambda-review` implementation was preserved.

support only when all implemented tools are declared. Regression coverage
checks the manifest/factory name set, package version, missing declarations
and partial declarations.
